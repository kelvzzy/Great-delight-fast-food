### What Works Right Now

**Customer Flow:**

2. Browses categorized menu
3. Selects items with variants/options
4. Adds to cart
5. Reviews order
6. Enters name & phone
7. Submits order
8. Receives confirmation with order number
9. Tracks status in real-time

**Admin Flow:**
1. Staff logs into admin portal
2. Views dashboard with today's stats
3. Sees new orders instantly
4. Updates order status through lifecycle
5. Manages menu prices & availability
6. Generates QR codes for tables
7. Downloads QR codes for printing

## 💻 Quick Start Commands

```bash
# Install dependencies
npm install

# Setup environment
cp .env.example .env
# Edit .env with your database URL

# Setup database
npm run docker:up
npm run prisma:migrate
npm run prisma:seed

# Start development
npm run dev

# Run tests
npm test

# Build for production
npm run build
npm start
```
