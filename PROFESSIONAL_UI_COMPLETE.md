## 🎨 DESIGN SYSTEM

### Color Palette
```css
Customer-Facing:
- Primary: Orange-600 to Red-600 gradients
- Accents: Pink-600, Yellow-400
- Backgrounds: Orange-50, Red-50, Pink-50

Admin Portal:
- Dark: Gray-900, Gray-800, Gray-700
- Accent: Orange-600 to Red-600
- Highlight: Yellow-400
- Text: White, Gray-300, Gray-400
```

### Typography Scale
```css
Headlines: text-4xl to text-6xl (36-60px)
Subheadlines: text-2xl to text-3xl (24-30px)
Body: text-lg to text-xl (18-20px)
Prices: text-2xl with gradient (24px)
Labels: text-sm with font-bold (14px)
Small Text: text-xs (12px)
```

### Spacing System
```css
Cards: p-6 to p-8 (24-32px)
Gaps: gap-3 to gap-6 (12-24px)
Rounded: rounded-xl to rounded-3xl (12-24px)
Shadows: shadow-lg to shadow-2xl
```

### Animation Timing
```css
Fast: 150-200ms (hover states)
Standard: 200-300ms (transitions)
Slow: 3-7s (blob animations)
Easing: cubic-bezier(0.4, 0, 0.2, 1)
```

## 🎭 ANIMATIONS & MICRO-INTERACTIONS

### Keyframe Animations
1. **Blob** - Organic floating movement (7s infinite)
2. **Float** - Gentle up/down motion (3s infinite)
3. **Pulse** - Opacity fade (3s infinite)
4. **Slide-in-right** - Card entrance (0.3s)
5. **Spin** - Loading indicators (1s infinite)

### Interactive States
```css
Button Hover: scale-105, shadow-xl
Button Active: scale-95
Card Hover: shadow-2xl, border color change
Selected: scale-102, gradient background
Icon Hover: scale-110
Loading: spin animation
Badge: pulse animation
```
